## 通用布局模板

所有风格都可套用这套**左右分栏展示布局**：

```
┌─────────────────────────────────────────────────────┐
│  左侧（信息栏）              右侧（预览框）           │
│  XX / 20                     ┌──────────────────┐    │
│  大标题                       │                  │    │
│  ENGLISH SUB                  │   风格化插画/     │    │
│  ───                          │   动画预览区      │    │
│  描述文字...                  │                  │    │
│                              │                  │    │
│  • 标签1  • 标签2  • 标签3    │                  │    │
│                              └──────────────────┘    │
│  PALETTE ●●●●●                                     │
│  NOW PLAYING ──────── 00:03 / 00:10                │
└─────────────────────────────────────────────────────┘
```

**结构要素**：
- 背景：深色渐变（#0a0a0f ~ #1a1a2e）
- 左侧：宽约 35%，大数字 + 标题 + 描述 + 标签 + 色板
- 右侧：圆角矩形预览框，宽约 60%，内边距 20px
- 底部：NOW PLAYING 进度条 + 时间码

## 1. 逐帧手绘水彩
**配色**：米白 + 墨绿 + 砖红 + 天蓝（自然手绘感）
**元素**：水彩晕染的小屋/树木/远山，蓝铅笔起稿线
**动画**：淡入出现、水彩晕染扩散、镜头缓慢推近
**适用**：治愈系、生活类、乡村/自然主题

## 2. 等轴2.5D
**配色**：多彩马卡龙色（粉/橙/蓝/绿）+ 浅蓝天空
**元素**：等轴测视角的小城建筑、道路、摩天轮
**动画**：建筑逐个弹起、窗户路灯一盏盏亮起、镜头环绕
**适用**：城市/社区/产品生态介绍

## 3. 扁平矢量
**配色**：深紫蓝 + 橙黄日落 + 粉紫天空
**元素**：扁平矢量风格的城市天际线、亮灯窗户
**动画**：无限推进缩放、窗户灯光逐个亮、无缝循环
**适用**：都市生活、科技产品、时间流逝感

## 4. 金线流动动画
**配色**：深藏蓝 + 金色细线
**元素**：数百根金色丝线像丝绸一样流动，排成连绵山脊
**动画**：线条随风飘动、镜头向前滑行、光束沿山路延伸
**适用**：高端品牌、自然/山脉/旅程主题

## 5. 3D糖果渲染
**配色**：粉/黄/蓝马卡龙色 + 浅粉背景
**元素**：光滑糖果质感的方块、金属圆环、玻璃珠
**动画**：方块落下搭成领奖台、圆环旋转着落定、景深虚化
**适用**：产品发布、排行榜、里程碑庆祝

## 6. 粒子形变动画
**配色**：深蓝底 + 冰蓝色发光粒子
**元素**：七千个光点组成文字/图形，不断形变
**动画**：粒子聚拢成字形 → 散开 → 聚成下一个形状，卷起气流
**适用**：概念解释、关键词强调、转场

## 7. 贴纸风科普
**配色**：深绿切割垫 + 模切贴纸（白边+投影）
**元素**：靶心图标、场记板图标、步骤标签、马克笔箭头
**动画**：贴纸啪啪地贴下、反光扫过、镜头巡游步骤
**适用**：步骤科普、教程类、流程讲解

## 8. 赛博朋克HUD
**配色**：黑底 + 紫/品红霓虹 + 青色UI元素
**元素**：雷达、高度速度带、数据读数框、点云城市
**动画**：扫描波一圈圈扩散、UI元素逐个弹出、目标锁定框
**适用**：科技/航天/数据监控类主题

## 9. 拼贴剪贴风
**配色**：牛皮纸棕 + 杂志剪报色 + 彩色字母
**元素**：杂志标题字、拍立得照片、和纸胶带、红印章
**动画**：纸张一张张撕下落定、树影扫过桌面、定格帧
**适用**：生活vlog、个人记录、复古手账感

## 10. 弥散渐变玻璃拟态
**配色**：紫/粉/橙极光渐变 + 半透明玻璃
**元素**：玻璃拟态卡片、时钟数字、播放按钮
**动画**：玻璃卡片从药丸里长出来、玻璃球掠过折射、渐变色流动
**适用**：App/产品展示、现代UI风格

## 11. 复古Synthwave
**配色**：深紫底 + 品红/霓虹粉网格 + 橙黄落日
**元素**：透视网格公路、条纹落日、棕榈树剪影
**动画**：光线步进地形、网格向前滚动、VHS扫描线叠加
**适用**：怀旧/复古/80年代主题、音乐类

## 12. 像素风
**配色**：深色夜空 + 紫/绿/蓝像素色板
**元素**：像素角色、瀑布、森林、红心生命数
**动画**：抖动渐变色、瀑布循环流动、提灯照亮森林、视差滚动
**适用**：游戏/怀旧/年轻向内容

## 13. 液态金属流动
**配色**：深紫底 + 银色镜面金属
**元素**：液态金属水滴、皇冠水花、镜面播放键
**动画**：液态金属落进暗场、融合升起、凝成镜面形状、高速慢放
**适用**：高端科技、产品发布、品牌片头

## 14. 悬浮界面2.5D
**配色**：深蓝底 + 蓝/白/绿色UI
**元素**：悬浮的剪辑软件界面、时间线、监视器窗口
**动画**：CSS 3D图层悬浮、景深切换、光标点击效果
**适用**：软件/工具类介绍、口播视频配图

## 15. 数据新闻编辑风
**配色**：米白报纸底 + 黑字 + 红色强调
**元素**：衬线大标题、双栏正文、折线图、荧光笔标注
**动画**：文字逐行出现、图表生长、镜头像读者视线一样游走
**适用**：深度科普、数据报告、观点输出

## 16. 水墨国风
**配色**：宣纸米白 + 墨黑 + 朱红印章
**元素**：远山、松树、渔舟、红日、飞鸟
**动画**：墨晕扩散成山、松树笔触画出、镜头推进画里、朱印落下
**适用**：文化/哲学/东方美学主题

## 17. 蓝图工程图
**配色**：深蓝底 + 白色工程线 + 黄色标注
**元素**：麦克风爆炸视图、尺寸标注、引线、图纸标题栏
**动画**：轮廓线逐个画出、尺寸标注跟着零件走、零件组装起来
**适用**：产品结构、原理拆解、工程类主题
