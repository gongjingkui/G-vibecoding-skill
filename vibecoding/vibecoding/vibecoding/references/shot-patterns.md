## 1. 开场标题页
**适用**：视频开头，抛出问题或主题
**元素**：大标题 + 副标题 + 装饰性场景（餐桌/图标/氛围光）
**动画**：标题淡入上移、场景元素 stagger 入场、背景光缓慢漂移

## 2. 对比等式页
**适用**：抛出反常识观点（"X ≠ Y"）
**元素**：中间大等式符号 + 两侧对比项 + 底部信号条
**动画**：标题 pop-in、两侧卡片左右滑入、底部脉冲信号灯

## 3. 流程图页
**适用**：解释一个机制（如"胃→激素→大脑"）
**元素**：左侧器官/图标 → 箭头 → 右侧目标，中间标注分子名
**动画**：箭头 scaleX 绘制展开、标签淡入、目标 pop 放大、旅行光点沿箭头移动

## 4. 天平平衡页
**适用**：两个对立概念的平衡关系（如"饥饿素 vs 瘦素"）
**元素**：左右两侧激素卡片 + 中间平衡球 + 推拉箭头
**动画**：左右卡片对称滑入、中间球 pop 出现、平衡球缓慢脉动

## 5. 链式因果页
**适用**：解释一个连锁反应过程（如"饿过劲→酮体供能→警报静音"）
**元素**：多个节点卡片横向排列，用箭头连接
**动画**：节点逐个 stagger 出现、箭头依次亮起、底部横幅最后弹出

## 6. 三卡片并列页
**适用**：列举三个并列因素/方法
**元素**：三张等宽卡片，每张含图标+标题+说明
**动画**：卡片 stagger 上浮入场、图标上下浮动

## 7. 左右分栏页
**适用**：对比两个分类（如"情绪 vs 药物"）
**元素**：左右两栏，各有标题+标签 chips+说明文字
**动画**：左栏左滑入、右栏右滑入、chips 逐个 pop

## 8. 警告提示页
**适用**：需要警惕的信号/症状列表
**元素**：顶部警告三角 + 标题 + 底部症状 chips
**动画**：警告三角持续脉动、症状 chips 逐个 stagger 出现

## 9. 数字列表页
**适用**：编号步骤清单（如"第一/第二/第三"）
**元素**：大号数字徽章 + 标题 + 下方多个小元素排列
**动画**：数字徽章 pop、小元素逐个 stagger 入场、元素上下浮动

## 10. 食物网格页
**适用**：展示一组推荐/不推荐的事物
**元素**：N 列网格，每格含图标+名称
**动画**：卡片 stagger 上浮、重点项加发光效果

## 11. VS对比页
**适用**：坏习惯 vs 好习惯对比
**元素**：左右两栏，分别用红色/绿色主题
**动画**：左栏左滑、右栏右滑、中间 VS 符号淡入

## 12. 片尾总结页
**适用**：视频结尾，总结金句 + 互动引导
**元素**：大字号金句 + 爱心/点赞图标 + CTA 文案
**动画**：金句淡入上移、爱心持续跳动、CTA 最后淡入

## 动画工具函数（scene.js）

```javascript
import { easeOut, clamp } from './scene.js';

// 淡入：0=完全透明, 1=完全不透明
el.style.opacity = String(easeOut(clamp(t / duration)));

// 上浮入场
el.style.transform = `translateY(${(1 - easeOut(clamp(t / dur))) * 30}px)`;

// 缩放入场
el.style.transform = `scale(${0.7 + 0.3 * easeOut(clamp(t / dur))})`;

// 持续脉动
const pulse = 1 + 0.05 * Math.sin(t * 3);
el.style.transform = `scale(${pulse})`;

// 持续浮动
el.style.transform = `translateY(${Math.sin(t * 2) * 5}px)`;
```

## 13. 数据大屏页
**适用**：展示一个核心大数字 + 辅助数据（如"162个国家和地区"）
**元素**：中央超大数字 count up + 底部滚动数据表格行 + 屏幕边框HUD风格
**动画**：
- 大数字从0开始滚动到目标值（countUp 函数）
- 背景表格行无限向上滚动
- 中央数字带光晕，最后弹出副标签

```javascript
// 数字滚动核心逻辑
function countUp(el, t, a, b, to) {
  const p = easeOut(clamp((t - a) / (b - a)));
  el.textContent = String(Math.round(to * p));
}
// 用法：countUp(document.getElementById('bigNum'), t, 1.0, 3.0, 162);
```

## 14. 柱状图页
**适用**：对比多个类别数值大小（如"各城市降雨量"）
**元素**：N根柱子从底部基线生长到目标高度 + X轴标签 + Y轴刻度
**动画**：
- 柱子从底部 scaleY=0 生长到目标高度（transform-origin: bottom）
- 柱子逐个 stagger 生长
- 柱子顶部数字最后淡入
- 高亮当前对比项用金色，其他用灰绿色

```css
.bar { width: 60px; background: var(--teal); transform-origin: bottom; border-radius: 8px 8px 0 0; }
```
```javascript
// 柱子生长
bar.style.transform = `scaleY(${p})`;  // p 从 0 → 1
```

## 15. 折线图页
**适用**：展示趋势变化（如"血糖波动曲线""体温变化"）
**元素**：SVG 路径 + 数据点圆点 + 坐标轴 + 当前位置跟踪点
**动画**：
- 折线用 stroke-dasharray + stroke-dashoffset 从左到右绘制出来
- 数据点依次 pop 出现
- 一个发光的跟踪圆点沿路径移动
- 参考虚线（警戒线）先淡入

```css
.line { fill: none; stroke: var(--gold); stroke-width: 3;
  stroke-dasharray: 1000; stroke-dashoffset: 1000; }
```
```javascript
// 路径绘制
path.style.strokeDashoffset = String(1000 * (1 - p));  // p 从 0 → 1
```

## 16. 环形进度图页
**适用**：展示百分比/完成率（如"每日目标完成度"）
**元素**：圆环 + 中心百分比数字 + 标签
**动画**：
- 圆环用 conic-gradient 从 0% 旋转填充到目标百分比
- 中心数字 count up
- 圆环缓慢脉动发光

```css
.ring { background: conic-gradient(var(--gold) 0deg, var(--gold) var(--deg), rgba(255,255,255,0.1) var(--deg)); }
```
```javascript
// 角度随进度变化
ring.style.background = `conic-gradient(var(--gold) ${deg}deg, rgba(255,255,255,0.1) ${deg}deg)`;
```

## 17. 数据表格页
**适用**：展示多行多列结构化数据（如"药物副作用对比表"）
**元素**：表格头 + N行数据行 + 高亮关键行
**动画**：
- 表头先淡入
- 数据行从上到下逐行 slide in（stagger 0.15s）
- 关键行整行高亮闪烁一次
- 表格底部有滚动感（可选）

```javascript
// 行逐行滑入
rows.forEach((row, i) => {
  const p = easeOut(clamp((t - 0.5 - i * 0.15) / 0.5));
  row.style.opacity = String(p);
  row.style.transform = `translateX(${(1-p)*-20}px)`;
});
```
